**From portfolio construction to FX structuring.** A research project that rebuilds, with public data, the analytical work of an FX desk from three angles: the **portfolio manager** who allocates across G10 currencies, the **investor** who hedges the currency risk of foreign assets, and the **structurer** who designs hedging products for corporate clients.

Every result is generated by tested code, and every methodological choice is justified in a working paper with a decision log.

## Key findings so far

*Monthly data, February 1999 - September 2026, US investor, forwards implied by covered interest parity.*

| | Carry (%/yr) | Mean excess return (%/yr) | Volatility (%/yr) | Max drawdown |
|---|---:|---:|---:|---:|
| NZD | +1.8 | +2.7 | 12.6 | 34% |
| AUD | +1.5 | +2.5 | 11.7 | 39% |
| CHF | -1.8 | +0.8 | 9.7 | 32% |
| JPY | -1.7 | -2.1 | 9.3 | 62% |
| Equally weighted (9 currencies) | | +0.4 | **8.1** | 39% |

- **Carry lines up with returns.** High-yielding currencies (NZD, AUD) earned the most, the low-yielding yen the least - the pattern behind the carry trade.
- **Carry has crash risk.** The AUD position lost 32% between June 2008 and January 2009, more than ten years of its average excess return.
- **The Swiss franc is a safe haven.** Negative carry, yet a positive excess return, because it appreciates in bad times.
- **Diversification works, estimation does not.** The equally weighted basket is less volatile than every currency in it, but no mean return is statistically significant (t-stat ≈ Sharpe × √years ≈ 1.15). Volatilities are estimated far more precisely than expected returns - the practical case for minimum-variance allocation.
- **The euro falls when sovereign risk rises.** A 10 bp widening of the BTP-Bund spread goes with a 0.23% fall of EURUSD in the same month (t = -4.1), and a similar fall of EURCHF once the SNB floor of 2011-2015 is excluded. The rates channel works through long rates: a 10 bp rise of the Bund relative to the US Treasury goes with a 0.58% rise of the euro.
- **Rolling costs matter even without trading.** Holding the basket costs about 0.18% a year in the base-case cost scenario, mostly from rolling the forwards every month; costs twice as high would erase its premium entirely.

Full tables, methodology and limitations: working paper, Sections 3, 4 and 6.

## Methodology at a glance

| Item | Choice | Why (decision log) |
|---|---|---|
| Frequency | Monthly, month-end spot | Interest rates are monthly; standard in the currency literature (D8) |
| Sample | Unbalanced G10 panel from January 1999 | Uses all available data without inventing any (D9) |
| Base currency | US dollar (EUR investor in Phase 3) | Comparability with published results (D10) |
| Excess return | $rx_{t+1} = S_{t+1}/F_t - 1$, $F_t$ from CIP | Simple returns aggregate exactly: $r_p = w'r$ (D11) |
| Timing | Positions use only data known at the end of month $t$ | No look-ahead bias, enforced by tests |
| Transaction costs | Swap half-spread on the notional rolled, outright half-spread on the notional traded | Holding a forward requires a monthly roll (D14) |
| Cost level | Stated assumption by liquidity tier, scaled by 0, 1, 2, 5; break-even scale reported | No free bid-ask data; results do not hinge on one figure (D15) |
| CIP rates | 3-month interbank rates; overnight risk-free rates (SOFR, ESTR, SONIA) as a robustness check | Market reference over most of the sample; switching changes returns by about 1 bp a month (D16) |
| Euro drivers | Monthly averages, OLS with Newey-West standard errors | Rates and yields are monthly averages; robust to autocorrelation (D18) |

## Data

All data are public and downloaded by script, so anyone can reproduce the results.

| Data | Source | Frequency |
|---|---|---|
| Spot rates, 9 G10 currencies vs USD | Federal Reserve H.10, via FRED | daily |
| 3-month interbank rates, 10 currencies | OECD Main Economic Indicators, via FRED | monthly |
| 3-month Euribor (extension after January 2026) | ECB Data Portal | monthly |
| Overnight risk-free rates: SOFR, ESTR, SONIA | FRED, ECB Data Portal | daily |
| 10-year government bond yields: US, DE, IT, FR, ES, CH | OECD Main Economic Indicators, via FRED | monthly |
| Forward rates | implied by covered interest parity | monthly |

## Getting started

```bash
git clone https://github.com/tomrousselet/fx-portfolio-lab.git
cd fx-portfolio-lab
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

pytest                                  # run the test suite
python scripts/download_data.py         # download the data (~20 s)
python scripts/describe_returns.py      # statistics table
python scripts/backtest_benchmarks.py   # dollar factor with transaction costs
python scripts/robustness_rfr.py        # CIP with risk-free rates
python scripts/euro_drivers.py          # what moves the euro
python scripts/make_figures.py          # figures
make -C paper                           # rebuild the paper PDF (requires a TeX distribution)
```

## Verification

The code is checked against independent results before it is used:

- **Course worked examples** (portfolio valuation, rebalancing, compounding) reproduced to the cent.
- **Closed-form checks** of the CIP forward, excess return and carry.
- **Timing tests**: an excess return must not change when later data change (no look-ahead).
- **Data tests**: quotation conventions and missing values, on synthetic files.
- **Backtest and costs by hand**: roll, resize and sign-change costs, long-short returns, collateral interest; with zero costs the forward backtest reproduces the descriptive statistics independently.
- **Performance measures** checked on series computed by hand.
- **Econometrics**: OLS coefficients recovered on simulated data, White formula reproduced independently, Newey-West errors wider under autocorrelation; splicing of rate series without a jump.

57 tests in total. The suite runs automatically on every push (GitHub Actions). The list of tests and what each one checks is in the paper, Appendix B.
